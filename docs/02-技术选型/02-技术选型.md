## 为什么作废

原文写于 Tailwind v3 时代，存在四类已被实测证伪的问题：

| # | 原文问题 | 实测事实 | 处置 |
|---|---|---|---|
| 1 | `Next.js 15` | 当前稳定版为 **16.3.8**；Next 16 还把 Middleware 约定改名为 Proxy | A3 / A39 |
| 2 | `npx shadcn@latest init` / `add button card ...` | shadcn CLI 已到 4.21.0，registry 路径与组件名重构（如 Pagination 现挂 `/docs/components/base/pagination`） | A3 / A37 |
| 3 | `npm install prisma @prisma/client` | `prisma` 的 npm `latest` 指向 **`8.0.0-rc.19`（预发布）**，与 `@prisma/client@7.10.0` 分叉；照抄会装错 | A38 |
| 4 | 认证写 `Supabase Auth / better-auth`，而依赖装 `next-auth`；全文无一个版本号 | 已定为 **Auth.js v5 + Credentials + Prisma Adapter**；全部依赖锁精确版本 | A4 |

此外 Prisma 7 是破坏性大版本：generator 必须用 `prisma-client`（非 `prisma-client-js`）、`output` 必填、连接串迁至 `prisma.config.ts`、运行时必须注入驱动适配器。

## 依赖安装方式（已变更）

不再手写 `npm install` 清单。规则见 `12` §4：

- **版本号不手写进 `package.json`**，由 `pnpm add <pkg>` 解析、lockfile 锁定；
- **唯一例外**：`prisma@7.10.0`、`@prisma/client@7.10.0`、`next-auth@5.0.0-beta.32`、`@auth/prisma-adapter@2.11.3` 四个包必须带显式范围（否则 `latest` 会装错）；
- `better-sqlite3`、`framer-motion`、`@types/bcryptjs` **不显式安装**（原因见 `12` §3.2）。
