- `*.vercel.app` 在**国内被 DNS 污染 + SNI 阻断**，无法访问。（本沙箱复现了同一现象：`*.vercel.app` 解析出非 Vercel 网段、连"故意不存在"的子域也返回 IP、TCP 443 超时；对照组 `registry.npmjs.org` 可达。）

- **决策**：**放弃公网访问**，展示方式改为 **GitHub 仓库 + 录屏**。
