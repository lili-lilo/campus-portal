## 1. 站点归属规则（**实测确认：无 Bug**）

### 1.1 关键：`seed.ts` 有一份**本地**的 folder 常量（v1 看漏的地方）

```ts
// app/prisma/seed.ts L492 —— 本地定义，carousel 在首位
const MEDIA_FOLDERS = ["carousel", "news", "dept", "leader", "other"] as const;
```

```ts
// app/src/lib/storage.ts L18 —— 共享常量，news 在首位（v1 误用了这一份 ⇒ 结论全错）
export const MEDIA_FOLDERS = ["news", "carousel", "dept", "leader", "other"] as const;
```

### 1.2 实际配对（按 seed 本地顺序）

```ts
const folder   = pick(MEDIA_FOLDERS, i - 1);                                        // 下标 i-1
const siteSlug = i % 5 === 0 ? null : pick(["main", "main", "cs", "ee", "ba"], i);  // 下标 i
```

两处下标确实相差一格，但站点数组**开头有两个 `main`**，恰好吸收了这一格偏移：

| 目录 | i 的取值 | `siteSlug` | 前台后果（实测） |
|---|---|---|---|
| `carousel/` | i ≡ 1 (mod 5) | **main** | ✅ 首页 Hero 查得到（`main` + `carousel` = **10 条**） |
| `news/`（媒体库） | i ≡ 2 (mod 5) | **cs** | 仅后台媒体库；无前台消费者 |
| `dept/` | i ≡ 3 (mod 5) | **ee** | 只有 ee 子站有横幅；cs/ba 走渐变兜底（与 `home-department.tsx` 注释一致） |
| `leader/` | i ≡ 4 (mod 5) | **ba** | 仅后台媒体库；无前台消费者 |
| `other/` | i ≡ 0 (mod 5) | **null** | 全站共享（当前无查询含 `siteId: null`） |

**live 数据库实测**（2026-10-05，Supabase 只读 SQL）：

```
carousel  main      10
dept      ee        10
leader    ba        10
news      cs        10
other     (null)    10
carousel 计数：main = 10 ; cs = 0
```

⇒ `page.tsx` **L128 的注释是对的**，Hero 查询正常返回 5 条（`take: 5`）。
⇒ 前端**只有 2 处**消费 Media 文件夹：`page.tsx` L130（`carousel`）、`home-department.tsx` L74（`dept`）；
   故 `leader→ba` / `news→cs` **当前不影响任何页面**。

### 1.3 v1 的错误结论（**已撤回，勿执行 v1 的 SQL**）

v1 断言「carousel 错挂 cs ⇒ 首页 Hero 恒空」并给出改 `siteId` 的 SQL。**该结论错误**（根因见 §1.1）。
那段 SQL 若执行会**把数据改坏**（把本来正确的 `main` 归属和 dept 归属改错），**已删除**。

### 1.4 实测查出的两个真问题（与 siteId 无关）

**① Hero 第 1 张是 PDF ⇒ 首屏第 1 张恒为渐变兜底**（**已修 · commit `6cd60ac`**：`carousel` 强制 `image`）

`i=46` 同时命中 `i % 23 === 0 → file`（type 规则）与 `i ≡ 1 (mod 5) → carousel`（folder 规则），
于是 `/uploads/seed/carousel/file-046.pdf` 成了**最新的 carousel 素材**。首页 `take: 5` 实际拿到：

| 顺序 | Media | 路径 | 结果 |
|---|---|---|---|
| 1 | `seed-media-46` | `/uploads/seed/carousel/file-046.pdf` | ⚠ `<Image src="*.pdf">` 破图 ⇒ **渐变兜底** |
| 2 | `seed-media-41` | `/uploads/seed/carousel/image-041.jpg` | 真图 |
| 3 | `seed-media-36` | `/uploads/seed/carousel/image-036.jpg` | 真图 |
| 4 | `seed-media-31` | `/uploads/seed/carousel/image-031.jpg` | 真图 |
| 5 | `seed-media-26` | `/uploads/seed/carousel/image-026.jpg` | 真图 |

修法（**一行，建议并入视觉改造批次**）：
`const type = folder === "carousel" ? "image" : i % 17 === 0 ? "video" : i % 23 === 0 ? "file" : "image";`

> ⚠ **陷阱**：`path` **不在** upsert 的 `update` 块里（L1288-L1301 只更新
> `siteId`/`type`/`name`/`size`/`mimeType`/`width`/`height`/`folder`/`album`），
> ⇒ 改规则后重跑 seed **不会**修正已有行的 `path`，会出现 `type=image` 而 `path` 仍是 `.pdf` 的脏行。
> 必须同时删掉受影响的行，或补一条 `UPDATE "Media" SET path = ... WHERE id = 'seed-media-46'`。

**② Hero 的叠字标题是占位文案**

`seed.ts` **L1291**：`name: \`种子素材 ${i}（${folder}）\`` ⇒ 首页轮播叠字显示「种子素材 41（carousel）」这类文字。
对"看不出和真 985 的区别"是硬伤。修法：给 carousel 素材写真实感标题，
或让 `page.tsx` 改成用关联文章的标题（`Article.mediaIds`，T2.2 已留 TODO）。
