#   1. NEXTAUTH_SECRET / NEXTAUTH_URL  →  AUTH_SECRET / AUTH_URL（Auth.js v5 命名，A4）

#                                        →  本期不用 Supabase Auth，仅用其 PostgreSQL
#                                           与 Storage；Storage 的访问走服务端凭据，
#                                           不需要这三个前端变量

#                                           prisma.config.ts 的位置一致）
#   6. 新增 NEXT_PUBLIC_SITE_URL         →  SEO 的 canonical / sitemap / OG 需要绝对地址
#
# 使用方式：
#   cp .env.example .env        # 然后填值；.env 不进仓库（见 .gitignore）
#
# 读取方说明：
#   - Next.js 进程：自动加载 .env / .env.local
#   - Prisma CLI（prisma.config.ts）：**不会**自动读取 .env，
