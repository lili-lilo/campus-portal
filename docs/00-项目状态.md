### 4.2 状态机（6 态，8 条边）

```
        ┌──────────────────────────────────────┐
        │                                      │
     draft ──①──> pending_first ──②──> pending_final ──③──> published
        ↑              │                     │                  │
        │              └──④──> rejected <────┘（⑤）              │
        │                        │                              │
        │                        └──────────────┐               │
        │                                       │               │
        └───────────────────── withdrawn <──⑥───────────────────┘
                  ↑
                  └──⑦──> pending_first（撤稿后重新提交）
```

- **关键定稿**：`rejected` 的唯一出口是 `draft`（**回草稿**，非直接回 `pending_first`），与 `withdrawn` 归口一致，状态图无特例分支
- `published` 后编辑：**先落 `ArticleVersion` 快照** → 转 `draft` → 前台立即不可见 → 必须重走两级审核（已接受"编辑期间短暂下线"）
- **5 条强制约束**：C1 每次状态变更必须写 `AuditRecord`；C2 服务端比对 `fromStatus` 防并发；C3 `published` 编辑前必须落快照；C4 editor 只能操作本人稿件；C5 前台一律 `status='published' AND deletedAt IS NULL`
