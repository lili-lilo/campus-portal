## 真做 vs 模拟

| 模块 | 真做 | 模拟/简化 |
|---|---|---|
| 主站首页 | 轮播、要闻、公告、院系入口、页脚 | 数据种子 |
| 新闻中心 | 列表、详情、分类、搜索 | 富文本详情 |
| 学校概况 | 简介、历史沿革、领导、组织机构 | 静态页 |
| 院系子站 | 2～3 个子站，独立首页、栏目 | 动态路由 [site] |
| 师资队伍 | 列表、筛选、检索 | 种子数据 |
| 招生就业 | 招生简章、计划、就业信息 | 静态+列表 |
| 信息公开 | 目录、年度报告 | 静态 |
| 全站搜索 | 标题/正文、高亮、分页 | ~~Fuse.js~~ → **Prisma `contains` 运行时检索**；Fuse.js 仅用于输入建议（A25） |
| 多语言 | 中英文切换 | JSON 语言包 |
| 无障碍 | 字体放大、高对比度 | CSS 变量（token 第 1 周落地，A36） |
| 后台登录 | 账号密码、角色 | Auth.js v5 + Credentials（A4） |
| 内容管理 | 文章 CRUD、审核、版本、回收站 | 状态机（6 态，A12） |
| 栏目管理 | 无限级树、类型、排序 | 真做 |
| 媒体库 | 上传、分类、预览 | ~~本地存储~~ → **StorageAdapter 双实现**：开发本地 `public/uploads`、生产 Supabase Storage（A33） |
| 用户权限 | RBAC、数据范围 | 真做简化版（Role/Permission 四表，A11） |
| 站点管理 | 主站+子站、模板绑定 | 真做 |
| 统计 | ~~PV/UV~~ → **图表真做、采集不做**：仅展示 seed 的 90 天数据，无埋点（A26） | 种子+图表 |
| 表单 | 自定义表单、导出 | 简化 |
| 评论留言 | 审核、回复 | 简化 |
| 系统设置 | ~~SEO、水印、日志~~ → **仅 SEO 分组等配置项**；水印不做（A18） | 简化 |
