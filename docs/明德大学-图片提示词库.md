## 使用说明

### 模型选择

| 场景 | 模型 | 单张积分 |
|---|---|---|
| Hero / 院系 / 子站 banner（重要图） | Seedream 5.0 Pro | ~14 |
| 要闻卡片 / 生活 / 缩略图 | Seedream 4.5 | ~7 |
| 领导头像 | Seedream 4.6 | ~7 |
| 缩略图批量 | Z-image Turbo | ~3 |

### 关键约束

1. **闭源模型无独立负向框** → 排除词写进正向末尾
2. **画面里不出现任何文字** → 校名/校徽后期合成
3. **参数只控三项**：提示词、参考图、分辨率/比例
4. **头像一致性**：同一次会话连续出图，不新开会话
