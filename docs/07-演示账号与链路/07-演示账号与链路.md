## 演示链路（2分钟）

### 1. 前台浏览（30秒）
- 打开首页，看轮播、要闻、公告
- 点击新闻详情，看富文本、附件
- 切换子站，看独立首页

### 2. 搜索与多语言（20秒）
- 搜索"招生"，看高亮结果
- 切换英文，看语言包

### 3. 无障碍（10秒）
- 打开无障碍，放大字体
- 切换高对比度

### 4. 后台操作（40秒）
- 登录 `admin`
- 看仪表盘统计图表
- 新建文章 → 填标题、正文、封面
- 提交审核（状态 `draft → pending_first`）
- **切换 `auditor` 登录**（右上角退出 → 用 `auditor/admin123` 登录）
- 审核通过（`pending_first → pending_final`）→ 发布（`pending_final → published`）
- 回前台看新文章

> **双账号切换说明**：`admin` 虽是 `super_admin`（有全部权限），但演示脚本刻意走"编辑提交 → 审核员批准"的**两人协作**路径，以展示审核流与角色隔离。
> 实际操作有两种方式：
> - **方式 A（推荐，体现权限隔离）**：退出 `admin` → 登录 `auditor` 完成终审。切换前建议先开一个隐身窗口登录 `auditor`，避免演示时手忙脚乱。
> - **方式 B（省时）**：全程用 `admin`，因为 `super_admin` 可执行所有状态转移。**但这会看不出 RBAC 的价值**，仅在时间紧张时使用。
>
> 另注：状态机为 6 态（A12），"审核通过"在 UI 上表现为两次动作 —— **初审通过**（→ `pending_final`）与 **终审发布**（→ `published`）。若只有 40 秒，可把两次点击连打，口播为"初审、终审、发布"。

### 5. 统计与收尾（20秒）
- 看文章排行
- 看栏目排行
- 看访问趋势
