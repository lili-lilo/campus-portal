## 一句话
一套轻量级高校官网站群系统作品集，支持主站+子站、内容审核、RBAC、全站搜索、多语言、无障碍，基于 Next.js + Prisma + Supabase，一条命令启动。

## 目标
- 明面上完整：主站 + 子站 + 后台 + 搜索 + 多语言 + 无障碍 + 统计
- 演示链路通：首页 → 新闻 → 详情 → 搜索 → 后台登录 → 发稿 → 审核 → 发布 → 看统计
- 技术轻量：一个仓库、一条命令启动、零成本部署
- 可复用：改配置和皮肤就能接类似项目

## 不做什么
- 不接真实 SSO、不接教务、不接短信、不接支付
- 不做等保、备案、迁移、培训
- 不做复杂工作流引擎，状态机即可
- 不做真实内容校对，全部种子数据

## 演示链路
1. 打开首页，看轮播、要闻、公告
2. 点新闻详情，看富文本、附件、分享
3. 搜索"招生"，看高亮结果
4. 切换英文，看语言包
5. 打开无障碍，放大字体、高对比度
6. 进后台登录，看仪表盘
7. 新建文章 → 提交审核 → 审核员通过 → 发布
8. 看统计图表、文章排行
9. 切换子站，看独立首页

## 目标受众
- 面试官、客户、同行
- 用于展示全栈能力、架构能力、UI 能力
