# 设计规范

> 本文件已被 `11-裁决记录` 补充（未推翻），冲突处以 `11`~`16` 为准。
> 补充处：① 本文档的色板/间距/圆角/阴影/断点需在**第 1 周（T1.3）落成 Tailwind v4 `@theme` token**，而非等到第 5 周（A36）；② token 必须额外包含**焦点环样式、高对比度主题变量、字号缩放变量（100%~200%）** 三套无障碍变量；③ 后台风格沿用本文档第 60~63 行。
> 数值本身（`#1a4f8b` / `#c9a961` / 1280px / 8px-12px 圆角 等）**不变**。

## 主色调
- 主色：深蓝 `#1a4f8b`（庄重、学术）
- 辅色：金色 `#c9a961`（点缀、高端）
- 背景：白色 `#ffffff` + 浅灰 `#f5f7fa`
- 文字：深灰 `#1f2937` + 中灰 `#6b7280`
- 边框：`#e5e7eb`

## 字体
- 中文：`"PingFang SC", "Microsoft YaHei", sans-serif`
- 英文：`Inter, -apple-system, sans-serif`
- 标题：font-weight 600-700
- 正文：font-weight 400，line-height 1.75

## 间距
- 页面最大宽度：1280px
- 内容区左右留白：24px（移动端 16px）
- 区块间距：80px（移动端 48px）
- 卡片内边距：24px

## 圆角
- 按钮：8px
- 卡片：12px
- 输入框：8px
- 图片：8px

## 阴影
- 卡片：`0 1px 3px rgba(0,0,0,0.06)`
- 悬浮：`0 4px 12px rgba(0,0,0,0.1)`
- 弹窗：`0 20px 40px rgba(0,0,0,0.15)`

## 动画
- 过渡时长：200-300ms
- 缓动：`cubic-bezier(0.4, 0, 0.2, 1)`
- 滚动揭示：Framer Motion `whileInView`
- 页面过渡：淡入 + 上移 20px

## 响应式断点
- sm：640px
- md：768px
- lg：1024px
- xl：1280px
- 2xl：1536px

## 无障碍
- 对比度 ≥ 4.5:1
- 焦点可见：`ring-2 ring-blue-500`
- 键盘可导航
- ARIA 标签完整
- 支持字体放大 200%

## 后台风格
- 侧边栏：深色 `#1f2937`
- 内容区：浅灰 `#f9fafb`
- 卡片：白色 + 圆角 + 阴影
- 表格：斑马纹 + hover 高亮
