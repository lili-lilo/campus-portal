### S2. 字体（含一处**必须修的既有缺陷**）

**缺陷（已在当前落盘文件中确认）**：`globals.css` 的 `@theme inline` 写了 `--font-sans: var(--font-sans)` —— **自引用**；而 `layout.tsx` 只提供了 `--font-geist-sans` / `--font-geist-mono`。结果：`font-sans` 与 `font-heading` 解析到**未定义变量**，`html` 上的 `font-sans` 实际回落为浏览器默认字体，`next/font` 加载的 Geist Sans **从未生效**。

**修法**：

- `--font-sans: var(--font-geist-sans), "PingFang SC", "Microsoft YaHei", "Noto Sans SC", ui-sans-serif, system-ui, sans-serif`（英文在前、中文栈在后；字族顺序：拉丁 → macOS 中文 → Windows 中文 → Linux 中文 → 系统回落）
- `--font-heading: var(--font-sans)`
- `--font-mono: var(--font-geist-mono), "SF Mono", "Menlo", "Consolas", "Liberation Mono", "Courier New", "PingFang SC", "Microsoft YaHei", ui-monospace, monospace`（与 `--font-sans` 同理，带 CJK 回落；T1.3 裁决补，原"不动"表述作废）
- 字重：标题 `600–700`；正文 `400`
- 行高：正文 `1.75`（→ `--leading-body: 1.75`；08 唯一行高数值）
- **字号阶梯：08 未规定 → T1.3 不自创**，沿用 Tailwind v4 默认 `--text-xs … --text-9xl`。无规格依据的自创阶梯属过度设计。

### S3. 焦点环（**覆盖** 08 原文的 `ring-2 ring-blue-500`）

**实测前提**：shadcn 4.21 的控件统一为 `outline-none focus-visible:border-ring focus-visible:ring-3 focus-visible:ring-ring/50`。即焦点指示 = **3px 环 @50% 透明度** + **1px 全不透明边框**，颜色都取 `var(--ring)`。所以有效对比度必须按"**50% 合成到背景上**"计算。

| `--ring` 候选 | 50% 合成后对白 | 对 `#f5f7fa` | 合成在主色蓝上对蓝 |
|---|---|---|---|
| `#3b82f6`（= 08 原文 blue-500） | **1.85:1 ✗** | 1.80 ✗ | 1.51 ✗ |
| `#1a4f8b`（品牌蓝） | 2.49:1 ✗ | 2.43 ✗ | 1.00 ✗ |
| `#1f2937` | 3.05:1 ⚠ 贴线 | 3.00 ⚠ | 1.36 ✗ |
| **`#0f172a`（采用）** | **3.41:1 ✓** | **3.36:1 ✓** | 1.54 ✗ |
| `#000000` | 3.95:1 ✓ | 3.91:1 ✓ | 1.80 ✗ |

**结论：没有任何单一颜色能同时满足"浅色背景"与"品牌蓝背景"**。故定义为：

1. **浅色表面**：`--ring: #0f172a`（环 3.41:1 ✓，同时 `focus-visible:border-ring` 的不透明边框对白 **17.4:1**）。
2. **深色 / 品牌色容器内**（页头、主色按钮、后台深色侧边栏）：局部覆盖 `--ring: #ffffff`（对主色蓝 **8.28:1** ✓）。
   → **这是第 2 周写 `SiteHeader` / `AdminSidebar` / 主色按钮容器时的必做项，不是可选项**；**禁止**通过修改 28 个 shadcn 文件来实现（那正是 A36 要避免的返工）。
3. **高对比度模式**：`--ring: #000000`（3.95:1 ✓）。
4. 环宽沿用 `ring-3`（3px ≥ 08 的 2px）。

### S4. 高对比度主题（`html[data-a11y-contrast="on"]`）

08 原文只有"对比度 ≥ 4.5:1"一句，**无变量定义** → 本节为新增权威值。原则：**所有文字 ≥ 7:1**（超过 4.5:1 下限），**去掉浅灰底**，**边框提为黑**，辅色改用可作文字的金。

| `--background` | `#ffffff` | `#ffffff` | — |
| `--foreground` | `#1f2937` | `#000000` | 21:1 |
| `--primary` | `#1a4f8b` | `#0b3a6b` | 11.46:1 |
| `--primary-foreground` | `#ffffff` | `#ffffff` | 11.46:1 |
| `--surface` | `#f5f7fa` | `#ffffff` | 取消浅灰 |
| `--muted` / `--accent` / `--secondary` | 浅灰系 | `#ffffff` | 与黑边框配合 |
| `--muted-foreground` | `#6b7280` | `#1f2937` | 14.68:1 |
| `--border` / `--input` | `#e5e7eb` | `#000000` | 21:1 |
| `--card` / `--popover` | `#ffffff` | `#ffffff` | — |

### S5. 字号缩放（`html[data-a11y-font="…"]`）

08 原文只有"支持字体放大 200%"，**无阶梯、无量纲** → 本节为新增权威值。

- **阶梯 5 档**：`100` / `125` / `150` / `175` / `200`（覆盖 100%~200%）。
- **机制**：`html { font-size: calc(1rem * var(--font-scale, 1)) }`；`html[data-a11y-font="125"] { --font-scale: 1.25 }`，其余同理。Tailwind 的字号与间距均为 **rem** → 整体等比放大，符合 WCAG 1.4.4 的推荐做法。
- **rem/px 策略（关键）**：
  - **断点用 rem** → 根字号放大时 `md:`/`lg:` 提前命中，布局自动切到窄屏形态；
  - **页面最大宽 `--container-page` 用 px** → 容器不随字号变宽，**避免 200% 时横向溢出**。
- **持久化与首帧**：`localStorage`（键 `campus-a11y`，值 `{font, contrast}`），并在 `<head>` 用**阻塞式内联脚本**在首帧前写 `<html>` 属性 —— 避免 FOUC 与 hydration 不一致。
- **服务端渲染默认值**：`<html data-a11y-font="100" data-a11y-contrast="off">` 必须由 SSR 输出，`16` 第 95 行的断言依赖它。
- **不可触碰**：`layout.tsx` 的 `LayoutProps<"/">` 写法不变（`00` §5.3）；新增内联脚本不影响该类型。
- 属性名以 `docs/16` 第 95 行为**唯一权威**（`data-a11y-font` / `data-a11y-contrast`）。
